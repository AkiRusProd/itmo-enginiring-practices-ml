# Руководство по деплою

## Инфраструктура ClearML

В этом проекте используется ClearML для отслеживания экспериментов, управления моделью и управления датасетами.

### Локальный деплой через Docker

1.  **Установите Docker и Docker Compose.**

2.  **Запустите сервер ClearML:**
    Используйте предоставленный docker-compose файл:
    ```bash
    docker compose -f docker-compose.clearml.yml up -d
    ```

3.  **Откройте веб-интерфейс:**
    Перейдите в браузере по адресу [http://localhost:8080](http://localhost:8080).

4.  **Настройте креды:**
    *   Перейдите в **Settings > Workspace**.
    *   Создайте новые креды (Access Key & Secret Key).
    *   Вставьте их в свой `.env` файл на основе существующего `.env.example`.

## Деплой документации

Документация автоматически деплоится в GitHub Pages с помощью GitHub Actions.

*   **Триггер:** пуш в ветку `main`.
*   **Workflow:** `.github/workflows/gh-pages.yml`
*   **Процесс:**
    1.  Устанавливает зависимости.
    2.  Генерирует последний отчёт об экспериментах (`src/generate_report.py`).
    3.  Собирает сайт с помощью MkDocs.
    4.  Загружает артефакты в ветку `gh-pages`.
